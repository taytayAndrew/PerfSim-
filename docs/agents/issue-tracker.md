# Issue Tracker

Issues live in GitHub Issues for this repository: **taytayAndrew/PerfSim-**

## Workflow

- Use `gh issue create` to create issues
- Use `gh issue list` to list issues
- Use `gh issue view <number>` to view an issue
- Use `gh issue edit <number>` to edit an issue
- Use `gh issue close <number>` to close an issue
- Use `gh label create` to create labels

## Repository

- **Repo slug**: `taytayAndrew/PerfSim-`
- **Remote**: `git@github.com:taytayAndrew/PerfSim-.git`
- **CLI**: `gh` (GitHub CLI)

## Conventions

- Issues are written in Chinese (matching the project language)
- One issue = one deliverable unit of work
- Feature issues link back to the PRD or design doc section they implement
